## 序章：传奇赏金任务

> 用户原定开篇，保留设定、叙述口吻与笑点，仅整理排版、标点及错别字。后续剧情接第 3 节「开场实写：从酒吧到第一场战斗」。

主角名为 **DeadEye**，一个十字图案的眼罩盖住了左眼，是一名性格沉稳、不善言辞的星际赏金猎人。

他通过承接危险的赏金任务获取报酬，在宇宙中过着刀尖舔血的日子。谁也不知道眼罩下到底藏了什么。

武器名为 **Breaker**，是一把左轮枪，射速不快、弹容量不多，但单发威力惊人，尾弹为一发强力爆弹。

一次偶然的机会——好吧，其实就是吃坏东西拉肚子而已——在一个毫不起眼的马桶旁边，摇摇欲坠地贴着一则传说级赏金任务。

那是一个名为 **Overload** 的星球。

悬赏人 **Mr.B**——剪影是一个肥头大耳的家伙——需要你帮他去坐标 **（X:404 Y:∞ Z:NULL）**，寻找名为 **Void** 的遗物。

赏金的数目足够你吃一辈子小熊软糖。

你犹豫再三，咽了咽口水（一周没吃饱饭了），抱着对遗物的好奇，还是接下了任务。

差点用它擦了屁股……

**切镜头。**

你便抵达了 Overload。

这个星球地表充满了奇形怪状的红色水晶体。经过这些水晶时，不知为何，你裤裆里的 Breaker 有种莫名的悸动。

**再切镜头。**

你一路寻找，却发现一间名为 **Chaos** 的破烂 Bar，正落在赏金任务所标的坐标位置。

## 1. 故事的方向

DeadEye 是一个认真做事的人，走进了一个把荒唐事当日常的地方。

他的目的始终具体：拿到 Void，领钱，吃饭。发现任务有问题之后，他也不突然发表拯救宇宙的演说。他先想活着出去，再发现唯一的出口在更下面。

幽默来自环境、办事规则和角色之间的错位。DeadEye 不负责讲段子；很多笑点靠他停顿一秒、收起枪，或者重新拔出来完成。厕所笑话在开篇完成使命，后面逐渐换成旅馆、失物、客房服务和失踪人口的荒诞。

主线承诺是：**向下打十层，找到一件“谁也没有见过”的遗物，最后弄明白为什么没人能描述它。**

从 Chaos 门口算起，目标是在约 30 秒内交还操作，45 秒内开始第一场交火。十层里的强制剧情主要放在开门、下楼、奖励落地时，通常只有两三句话；人物往事放进自愿交谈与拾取物描述。

## 2. 双武器的解释：一把随身枪，两种独立火力

### 推荐设定：Breaker 是枪，也可以成为一把钥匙

Overload 地下的红水晶具有两种性质：

- 能在受限空间里折叠、存放物体。
- 受到真实战斗的能量冲击时，会产生可回收的共振。

过去，地下设施利用这些水晶建造仓库、运输通道和军械库。现在设施失控，部分房间与库存仍然运行。

Chaos 发给住客的“房牌”，本质上是一枚旧式空间接口。它会扣在武器上，用武器承担瞄准、握持和开火控制，再用积攒的超载能量临时展开一件库存重火器。

于是，DeadEye 平时只携带 Breaker。

发动重火器时，房牌裂开一道红光，折叠的炮身围绕持枪手展开；开火、退膛，巨大零件重新缩回。整个动作在战斗中完成，不停下走路、不进入演出镜头，也不把左轮举到天上等变身。

**玩家看到的是“这把左轮突然变成了不该装得下的东西”。系统仍然保留主武器槽与重火器槽，能独立更换。**

### 第一次只解释一句

> 闩叔：“小枪是你的。大的，借楼下的。”

实际按一次重火器键，比一段世界观旁白有效。

后面遇到强化商人，才补充：

> 莫拉：“别把它当第二根枪管。那是一扇门。”

### 为什么高风险动作能够充能

设施把每间仍在交火的房间当作一个活跃共振区，房牌负责回收其中的能量：

| 现有玩法 | 剧情表现 |
|---|---|
| 主武器命中 | 房牌吸收目标附近的一缕红色回波 |
| 爆炸尾弹 | 爆压沿枪身回流，给接口一记明显脉冲 |
| 完美换弹 | 在膛压回落的准确瞬间闭锁，收回本来会散掉的能量 |
| 翻滚擦弹 | 房牌捕获贴身掠过的弹道扰动，红色电弧沿衣角划过 |
| 弱点打断 | 截获敌人蓄力机构突然失控的高强度放电 |
| 战术机关、充能核心 | 回收器针对爆炸、消弹、连杀等不同事件进行调谐 |

“回收器”可以是 NPC 的口语称呼，界面继续使用已建立的“充能核心”。超载仍是同一条能量，不新增第二条资源。

设施的回收阀只在真实敌对交火中打开。因此清房后对墙开枪、空换弹都不会充能；商店直接补给电池属于补充储能，仍然有效。重火器的放电本身不循环喂回能量。

### 重火器如何掉落，为什么能更换

掉落物是一枚“军械签”：保存某件折叠军械的规格与访问地址。插入房牌，就能把当前展开的重火器换掉。

- 45 能量：轻型军械，如五枚追踪弹。
- 65 能量：中型军械，如贯穿轨道炮。
- 90 能量：重型军械，如奇点发生器。

每件重火器保留现有独立消耗、冷却与后坐力。房牌只能维持一个军械地址，解释了为什么玩家同时只能装备一种重火器。

这也不要求所有角色都拿 Breaker：其他猎人的房牌分别接在自己的枪上。

### Breaker 与随机主武器的关系

建议把“只有一把枪”理解为 **DeadEye 登场时只有一把本命枪**。Breaker 是默认装备，也是剧情动画里的身份标志；进入地下之后，捡来的霰弹枪、冲锋枪是本局临时使用的军械。Breaker 收在枪套里，接口可以转接。

这样能保留现有主武器掉落和换弹流派，角色也有清晰标识。剧情镜头从当前武器切回 Breaker 时，给一个收枪、拔枪的小动作，避免凭空换枪。

如果最终坚持“DeadEye 整个流程都只能用 Breaker”，可以把主武器掉落改成不同枪身构型。但左轮变冲锋枪会削弱它的辨识度，文案、动画和装备系统也都要跟着改。这版优先采用前一种方案。

## 3. 开场实写：从酒吧到第一场战斗

### 场景一：CHAOS BAR

Overload 的风卷着红色晶尘。

DeadEye 停在坐标标记中央。

面前是间快散架的酒吧。招牌上写着 **CHAOS**。下面有一行很小的字：

**酒水 · 住宿 · 失物招领**

门口挂着“正常营业”。

屋里传来一声爆炸。

牌子翻了一面，还是“正常营业”。

DeadEye 推门。

吧台后站着一个瘦得像衣帽架的男人。他正在擦一只杯子。杯底早就没了，抹布却一直是湿的。

DeadEye 将悬赏单放到吧台上。

男人看了一眼，又看了看纸的下边缘。

**闩叔：**“你从厕所拿的。”

DeadEye 没回答。

**闩叔：**“这张算干净。”

DeadEye 指向坐标。

**DeadEye：**“Void。”

闩叔转身，从钥匙墙上摘下一个不存在的挂钩。

挂钩离开墙面时，才显出钥匙的轮廓。

**闩叔：**“楼下。十层。”

**DeadEye：**“楼梯？”

**闩叔：**“消防没批。”

他把一枚红水晶房牌推过来。

房牌从台面弹起，啪地扣在 Breaker 的枪身侧面。

左轮的弹巢转了半圈。

DeadEye 把手按在枪上。

**闩叔：**“别紧张。押金没那么贵。”

吧台边，一台锈迹斑斑的行李秤亮起绿灯。

**闩叔：**“站上去。办入住。”

此时交还操作。目标提示只显示：**站上行李秤。**

### 场景二：无障碍下楼

DeadEye 踏上秤。

屏幕依次显示：

**体重：合格**  
**随身武器：一件**  
**随身烦恼：超重**

闩叔按下“寄存”。

秤台弹出金属边框，将 DeadEye 连人带枪压成一张等身高的硬纸行李牌。

只保留一个短促、卡通式的二维压扁动作。

DeadEye 的右眼向下看了看。

闩叔捏起纸牌，塞进脚边只有信封宽的行李投递口。

**DeadEye：**“……”

**闩叔：**“手脚别伸到纸外。”

纸牌滑进黑暗。

传来一次枪声。

投递口吐出一小团烟。

闩叔看了一眼柜台上的规则牌，补上一行：

**运输途中请勿开火。**

### 场景三：负一层，失物招领

一条传送带把 DeadEye 吐进地下。

他在半空展开，落地，站稳。

身后行李口立刻缩成一条细缝。

顶灯逐盏亮起。周围是堆到天花板的箱子、衣服和枪套。

一台服务机器滑过来，扫描他胸口的行李标签。

**机器：**“无领取人。”

它的手臂展开枪管。

**机器：**“开始拆件。”

第一发子弹打碎 DeadEye 身旁的空箱。

**战斗开始。**

不锁镜头，不播放 Boss 介绍。玩家先射击，再翻滚；场地里的箱子和可升起的护盾直接承担掩体教学。

第一轮尾弹命中：Breaker 枪口出现明显爆光，目标身后的小群敌人被爆炸扫开。

弹巢见底，换弹条出现。玩家完成一次换弹后，房牌亮起。

**闩叔，广播：**“房牌带的电够你试一次。右边那个扳机。”

首次教学的房牌预存一发默认重火器所需的能量；这是一次性入住发放，后续靠战斗回收，不在每次下楼时反复补满。

按下重火器键。

Breaker 前方裂开一道红色缝隙。远大于左轮本身的炮管从里面展开，金属锁环扣住持枪手。

一道贯穿射流，把冲来的服务机器和后排炮塔打成飞散零件。

炮身瞬间收回。

DeadEye 看了一眼手里的左轮。

**DeadEye：**“我的枪？”

**闩叔：**“小枪是你的。大的，借楼下的。”

**DeadEye：**“收费？”

**闩叔：**“你已经在付了。”

DeadEye 抬头，看向摄像头。

下一波机器撞开卷帘门。玩家继续战斗。

这句“已经在付了”前期听起来像老板的损话，第七层才给出确切含义。

### 场景四：第一扇选择门

清房脉冲扫过。两道门解除锁定。

门上分别亮起枪械与工具标志；若生成第三道未知事件门，才出现问号。

枪械门旁有一个红水晶插槽。

**闩叔：**“往里加电，给你开好一点的库房。”

**DeadEye：**“代价？”

**闩叔：**“保安也好一点。”

提示：**可消耗超载能量升级下一间房的危险与奖励。**

不强制押注，不补一段概率说明。玩家选门后直接进入下一场。

## 4. 十层主线：每次下楼，只多知道一件事

每一“层”是一个主题区域，内部继续使用工程现有的多房间路线、整备站和层末 Boss；不是把完整流程缩成十个战斗房。

### 第一层：失物招领处

**画面：** 传送带、行李架、破箱子与红晶分拣臂。货架标签写着“雨伞”“义肢”“未领取的丈夫”。

**战斗：** 服务机器与分拣炮塔；以歼灭房为主，教射击、尾弹、换弹、擦弹、重火器与门前押注。

**人物：** 第一处安全整备站遇到黑市商人尼布。他把摊位藏在一个外面很小、里面很大的旅行箱里。

**层末 Boss：**“招领主任”，吊在轨道上的多臂分拣机。抓取臂、扫描头分别可破坏。

击败它后，DeadEye 从内部滚出的纸卷里找到自己的照片。

照片下面写着：

**遗失物：DeadEye**  
**预计入库：今日**

他把照片翻过来。

没有悬赏编号，只有一间客房的印章。

**新增认知：** 这里在他到来前，就给他做了入库登记。

### 第二层：洗涤与消毒部

**画面：** 工业洗衣机、蒸汽管线、挂着装甲的旋转衣架。广播坚持把活人称作“顽固污渍”。

**战斗：** 冷却液区域、喷汽间歇、可射爆储罐；引入破坏信标房，把“清洗程序”作为信标组。

**人物：** 强化商人莫拉坐在一张牙科椅旁。她给 Breaker 接上检测线，抬眼看了看 DeadEye 的眼罩。

**莫拉：**“枪放这儿。眼睛留着。”

她拆下房牌外壳，露出两条输出回路。

**DeadEye：**“两条？”

**莫拉：**“一条喂你的炮。另一条，往楼下。”

**层末 Boss：**“滚筒夫人”，一台穿着礼服的巨型滚筒消毒机。战斗间歇不断把自己的裙摆吸进去。

**新增认知：** 玩家产生的能量，除了自用，还被设施悄悄收走了一部分。

### 第三层：样品陈列室

**画面：** 一排豪华展柜。许多柜子里什么也没有，但铭牌写得非常详细。

**人物：** 赏金猎人莫罗站在一具空棺材旁，正替 DeadEye 写悼词。

**莫罗：**“喜不喜欢‘他终于不再赶路’？”

DeadEye 看向棺材。

**DeadEye：**“窄了。”

**莫罗：**“可以改。”

他出示自己的悬赏单：同一个 Mr.B，同样巨大的报酬，但目标写着“遗体一具”，坐标却与 Void 完全一致。

**层末 Boss：**“防盗展柜”。先打碎独立警报装置，再打穿会移动、会开火的柜体。

展柜里只有一个空盒。取下盒子，屏幕出现：

**VOID：仍在原位。**

DeadEye 将盒子翻过来。

盒底刻着一张平面图。

平面图包围了他现在站着的整个房间。

**新增认知：** Void 很可能不是盒子里的一件东西。不同猎人正在被同一份任务引向同一个地方。

这里适合做前三层 Demo 的结尾：谜底推进一步，马上显示“下行通道已开启”，不靠长篇雇主独白解释骗局。

### 第四层：深夜厨房

**画面：** 炉灶、食品轨道、冷冻库。冷库里的红水晶袋上贴着“禁止再冷冻”。

**战斗：** 火焰扇区、冷却罐、传送带。整体仍保持俯视射击，传送带不改变翻滚时长。

**人物：** 赏金猎人咔嚓正躲在汤锅后拍摄一台屠宰机器。

**咔嚓：**“往左一点。”

DeadEye 开枪。

机器炸掉半边。

**咔嚓：**“它的左边。”

咔嚓给他看照片：地表的一块红晶，在偏振镜下呈现出钥匙、牙刷和半张人脸的轮廓。

**层末 Boss：**“主厨·九分熟”，一架悬挂式料理机；锅盖是盾，切割臂和火焰喷口可逐个破坏。

**新增认知：** 地表的水晶不是普通矿石，其中封存着被压缩的物品，甚至人。

### 第五层：静音客房

**画面：** 长廊和规格相同的客房。许多房间里仍在播放电视，却没有住客。床上留着人形凹陷。

**战斗：**“请勿打扰”警戒装置持续呼叫敌人；以破坏信标和短时生存房为主。

莫罗在一扇房门前挡住去路。他的任务单忽然更新，DeadEye 的照片出现在“待领取遗体”栏。

**莫罗：**“名单更新了。”

DeadEye 拔枪。

**莫罗：**“我讨厌临时加单。”

**同行战：莫罗。** 他用少量、清晰预警的高威力穿透射击制造翻滚节奏。击败是缴械，不演成杀死后复活。

战后任务终端给莫罗发来一条新指令：

**如无法完成交付，请自行替代。**

莫罗盯了两秒，把终端合上。

**莫罗：**“悼词改写给他。”

完成这场对决后解锁莫罗；本局仍由玩家当前角色继续，下局可在 Chaos 选择他。

闩叔在撤离电话里承认：这里原本是一家巨型旅馆，后来“客房容量优化”把住客也当作占用空间来处理。

**新增认知：** 悬赏单会把猎人重新定义成货物；Mr.B 要的东西与活着的人有关。

### 第六层：折叠军械库

**画面：** 巨大的枪械零件从小抽屉里伸出，武器货架向无法看见的远处延伸。

**战斗：** 层内更频繁给出军械选择，让玩家集中体验重火器构筑。保留正常随机与稀有度规则，不在剧情里许诺必掉金装。

**层末 Boss：**“军需管理员”，以三种能被拆掉的挂载武器轮换弹幕。

战后，莫拉接通房牌里的军械通信。

有人在另一头低声说：

**陌生声音：**“别让他把门关上。”

莫拉停下手里的工具。

军械签的旧档案展开：不少枪原来属于从此失踪的赏金猎人。

**莫拉：**“你借的炮，有人来不及还。”

她切断房牌中向下输送能量的旁路，保留玩家自己的回收与重火器接口。

**新增认知：** 重火器来自真实的遗失军械库。玩家一路作战，也在替更深处的装置供电；从此开始主动破坏这种利用。

### 第七层：住客档案馆

**画面：** 纸质档案与投影索引混在一起。抽屉能装下一整间客房，名字会从标签上自行消失。

**战斗：** 上传终端房。玩家边打边夺取记录，而不是停下来读十页电脑。

咔嚓拿到一张 Mr.B 的照片。他的照相机立刻显示：

**拍摄对象不存在。建议重拍。**

照片开始褪色。DeadEye 用房牌压住照片一角，留下了 Mr.B 肥大的侧脸。

**咔嚓：**“哈。原来不是我对焦的问题。”

**同行战：咔嚓。** 被自动摄影验证系统夺走相机控制后，系统将“图像中未登记的 DeadEye”列为清除对象。咔嚓本人不断报出镜头的扫射方向。打坏独立控制器即可缴械解除，不需把他的生命打空后强行救活。

救下咔嚓、保住底片后解锁他。

**此层明确揭示：** Void 是一间实验性“空房”。它能从外部的定位与归属系统中抹去内部的对象，但对象本身仍存在。失控设备把这些无法被查询、无人能够领取的东西统一处理成了“失物”。

**咔嚓：**“找不到，不等于没有。”

### 第八层：永远空着的婚宴厅

**画面：** 摆好餐具的宴会厅、结成红晶的花束、尺寸不对的座椅。仍有人在各处的折叠空间里敲墙。

**战斗：** 破坏三个空间固定器，每破坏一个就有部分房间恢复正常，落出补给与撤离标记。被救者只作为结算与演出，不增加护送 AI。

**层末 Boss：**“永恒司仪”，胸前固定着最后一枚主定位器。它反复宣布婚宴即将开始，攻击却瞄准每个试图离席的人。

破坏定位器，宴会厅另一侧终于显出一排疲惫的客人。

有人看着桌上的菜。

**客人：**“上齐了？”

画面角落，宴会时间显示为十七年前。

**新增认知：** 被藏起来的人还可能活着。Mr.B 从未通知任何救援机构，因为没有记录就不会产生失踪案。

此处减少笑话，让玩家第一次感到这里的荒诞对普通人意味着什么。

### 第九层：总统套房

**画面：** 极尽奢华的一层。门口堆着整箱从未拆封的小熊软糖，与地下饥饿的住客形成对照。

Mr.B 第一次不再用剪影。

一个肥胖男人穿着过小的浴袍，手里捏着两颗软糖。他的另一只手在远程控制防卫设施。

**Mr.B：**“赏金当然是真的。我付得起。”

他把托管资金证明投到墙上。

**Mr.B：**“你们打开十道锁，我就能把空房装进口袋。”

Void 原本被十层安全设施固定。Mr.B 的权限早已被事故后的隔离程序封锁；他能够投放委托和干扰局部系统，却不能亲自打开全部隔离层。因此他需要不断进入的外来猎人替他战斗、供电、逐层解除固定。

他准备把成功者作为新的活体定位锚，完成最后一次搬运。

DeadEye 看向托管证明上最后一行：

**签收对象：猎人及随身遗物。**

**DeadEye：**“连我一起？”

**Mr.B：**“运费已经包含了。”

DeadEye 开枪，打碎投影。

**层末 Boss：Mr.B 的“私人安保”。** 豪华座椅展开为武装平台，Mr.B 被安全气囊包得像一颗大软糖。先拆武装与护罩，再逼他开启通向第十层的逃生门。

**新增认知：** 赏金并非虚构，真正被隐瞒的是交付对象。猎人的贪念和本领都是任务设计的一部分。

### 第十层：VOID，零号空房

这里起初只是一个普通房间。

一张床。

一盏灯。

一面镜子。

Mr.B 站在镜子前，将主控房牌插入墙面。

镜子没有照出他的身影。

却照出了 Chaos 的吧台、洗衣房、军械库和刚被救出的客人。各处开始向镜中滑动。

**Mr.B：**“没有人记得的东西，总得有人接手。”

DeadEye 举起 Breaker。

镜子里的 DeadEye 比他慢了半拍。

最后才转过头来。

十字眼罩下，漏出一线与镜框相同的红光。

Mr.B 第一次失去笑容。

**Mr.B：**“你那只眼睛——”

Breaker 的爆炸尾弹打断他。

**最终 Boss：空房管理员。** Mr.B 强行取得的主控接口与整座房间融合，形成可读性清晰的分阶段场地战：

1. **办理入住：** 三个独立房间锚点制造弹幕，玩家可以逐个打掉，永久移除相应招式。
2. **行李超重：** 折叠军械展开，使用此前见过的重火器预警，让玩家通过擦弹、打断、重火器爆发掌握节奏。
3. **强制退房：** 已损坏的主控接口显露；用普通伤害即可完成战斗，不检查玩家是否还留着某把枪或某种能量。

最后一击后才播放短演出：DeadEye 对准主控房牌，打出 Breaker 的爆炸尾弹。

闩叔从紧急电话里喊来：

**闩叔：**“别打承重——”

爆炸。

**闩叔：**“……算了。”

崩塌的是 Mr.B 的搬运装置与控制权，不是 Void 本体。莫拉保住了通往 Chaos 的稳定接口；咔嚓此前上传的影像和档案，使救出的客人重新有了可追踪的身份。

Mr.B 被失控的行李回收臂夹走，压成一只写着“无人认领”的小皮箱。

箱子里还在讨价还价。

### 尾声：仍然营业

Chaos 吧台。

DeadEye 面前放着一杯水、一碗热食，以及一小包小熊软糖。

Mr.B 的悬赏托管端显示：**委托人已失去签收资格。**

尼布已经在替他们处理从总统套房搬出的物资。奖励来自实际带回的财物，首轮不把那笔天文数字轻易兑付成无限游戏货币；后续可以将索取正式赏金作为扩展剧情。

**闩叔：**“你想吃什么颜色？”

DeadEye 撕开包装。

**DeadEye：**“都行。”

他吃掉一颗。

左眼眼罩轻轻动了一下。

DeadEye 把包装按住，面无表情地看向吧台下面。

切黑。

行李投递口“叮”了一声。

**可选后续：** Void 内仍有未定位房间。猎人可返回 Chaos 结算，也可消耗超载开启更深的折叠支路，寻找住客和遗失军械。无限模式因此来自尚未搜尽的空间，不需要把主线结局撤销。

## 5. 三位常驻 NPC

### 酒吧兼旅馆老板：Latch／闩叔

**外观：** 瘦高、光头，穿黑马甲和已经发黄的白衬衫。领结是一把磨平的旧钥匙，腰间钥匙串长到快拖地。左袖永远挽得比右袖高一截。剪影像一根挂满东西的门闩。

**性格：** 慢、干、务实。可以面不改色地说明危险，通常只回答问到的部分。他不恶作剧，也不享受客人受苦；只是见过太多不肯听劝的猎人。

**真实身份与动机：** 老旅馆的前台主管，握着最后一个不受 Mr.B 完全控制的地表接口。多年里一直把折叠失物中的幸存者偷运回来。只能操作局部运输和回收，无法关闭地底主机；需要一个能活着打进去的人。

他知道任务有陷阱，但不知道 Void 的全部功能，也不知道 DeadEye 眼罩下是什么。隐瞒危险是他的道德污点，第五层应让 DeadEye 当面追问，不把他写成永远正确的导师。

**功能：** 下行入口、返回据点、角色选择与简短主线广播。

**声音：** 每句话像已经对前一百个客人说过。少用感叹号，不解释自己的笑话。

> “有房。安静的没有。”  
> “楼下那位住了八年。一直没找到退房按钮。”  
> “别打柜台。我还得用。”

### 黑市商人：Nib／尼布，“箱底先生”

**外观：** 矮小的鼠形外星人，一只镀金门牙能弹出扫描光。穿比自己大三号的旅行大衣，衣内缝满大小不一的口袋。摊位是一口带四只机械脚的旧皮箱。

**性格：** 爱钱，爱讨价还价，更舍不得扔东西。他会说谎，但对商品的致命缺陷必须讲清楚，因为自己也曾被“近乎全新”的装备炸掉过尾巴。

**私人动机：** 在遗失物里寻找女儿留下的一只红手套。手套主人是否还在，前期只用一个空着的小货架暗示。第八层可以在救出的客人中完成这条小支线，不要求跑回头路。

**功能：** 武器、军械签、充能核心、道具、刷新与补给。标明安全的商店不刷敌人；危险盲箱放在单独的未知事件房，保留安全门的可信度。

**声音：** 亲热、精明，喜欢谈物品的前任主人。交易之外，他的话明显更少。

> “九成新。剩下一成在上一位买家身上。”  
> “这是货。那只手套不是。”  
> “先问价，再问来历。顺序反了容易便宜。”

### 强化商人：Molar／莫拉，“拔牙师”

**外观：** 壮实的女外星人，灰蓝色皮肤，一颗醒目的金属犬齿。戴单目放大镜，皮围裙上插满精密工具。工作台是一张改装牙科椅，枪械被夹在头枕原来的位置。

**性格：** 强硬、耐心、讲手艺。对枪非常温柔，对拿枪的人没那么客气。她讨厌靠牺牲使用者来换纸面威力的设计。

**真实经历：** 曾负责地下军械的空间闭锁维修，发现设施把失踪住客当作可压缩库存后逃离。牙科工具来自她过去给矿工做义齿的副业，枪匠能力来自实际工作经历。

**功能：** 伤害与尾弹、换弹窗口与专属效果、弹道与弹容量、擦弹回收与护盾相关调校。她不会为了一个强化把玩家的基础翻滚落点改掉。

**声音：** 给诊断、给处理方法，不讲玄学。

> “张开。说你的弹巢。”  
> “枪没问题。拿枪的那个总抢拍。”  
> “把这根线剪了。你赚的电，凭什么分给他？”

## 6. 三位可操作猎人

以下数值与特性均为角色设计提案，尚未替换现有武器参数。三人共用基础移动、瞄准和翻滚规则；差异集中在初始主武器、重火器、核心和换弹反馈，避免每换角色都重新学习移动手感。

### DeadEye／死眼

**性格：** 沉稳、寡言，有饥饿和好奇心，但不会被这两点写成莽撞笨蛋。他观察细节，主动判断风险；偶尔一句非常实际的话产生冷幽默。

**外观：** 左眼戴黑色眼罩，缝着粗白线十字。短款旧风衣、磨损的护肩、右手露指手套。衣服整体暗而干净，枪柄与眼罩十字是主要识别点。不要再给他额外配发光护目镜，也不要让大面积霓虹盖过眼罩。

**人物秘密：** 本章只揭示眼罩与 Void 产生反应，不揭开眼罩，不让莫拉一眼看穿。他知道左眼不能露出来，但对地下设施为什么认得它同样意外。

**主武器：Breaker／破界者**

- **类别：** 六发重型左轮；无限后备弹药，但每轮必须装填。
- **外形：** 厚重短枪管、方形护框、磨白的黑色金属、暗红握把。弹巢最后一个常规弹位有一道白色刻痕，玩家能明确看出尾弹何时到来。
- **射击：** 慢射速、强单发、短促后坐力；一发一发有重量，不做成小冲锋枪。
- **尾弹「句号」：** 第六发是一枚高爆弹，击中后爆炸，对主目标造成高伤害并清理附近小群敌人。普通装填就能获得，不能要求先攒超载，否则核心循环会被绑在另一条资源上。
- **完美换弹「稳手」：** 下一轮前两发提高伤害与弹速，给准确节奏一个直接反馈。它与第六发爆弹是两种不同奖励。
- **失败换弹：** 保留现有短暂卡壳惩罚，表现为弹巢未完全闭锁。
- **初始充能方向：** 战术机关回收。利用燃料罐、冷却罐或折射机关命中敌人，可得到额外超载。
- **战斗风格：** 找角度，以精准重击收掉高威胁目标，再把尾弹送进密集敌群。

**初始重火器：Door Knocker／叩门者**

65 超载，沿用中型贯穿重炮定位。枪身在 Breaker 前方展开成过分粗大的方形炮管，发射一束高穿透射流。主要用途是同时打断精英与清掉一条线上的敌人；保留明确冷却，角色仍能移动。

后续装备别的军械签，可以变成蜂群或黑洞等形态。Breaker 的爆炸尾弹始终由主武器弹巢决定，与重火器键互不占用。

**代表对白：**

> “开门。”  
> “我问的是活着的出口。”  
> “吃的留下。”

### Morrow／莫罗，“明日送葬人”

**性格：** 礼貌、爱说话、非常守约。相信每个人都值得有一个体面的结尾，连敌人也包括在内。他把战场当工作现场，却会为一个无名死者耽误赚钱。

**外观：** 细长身形，灰白面孔，黑色短礼服配防弹内衬。半边帽檐被烧掉，胸口插一朵纸花。背后是扁平的折叠棺箱，整体形成清晰的竖长剪影。

**来此原因：** 接到一份高额遗体回收任务。先把 DeadEye 看作竞争者，后来发现雇主只是在给“下一具遗体”寻找搬运工。

**主武器：Amen／安息**

- **类别：** 两发折管式精确步枪，无开镜要求，继续使用俯视瞄准。
- **外形：** 枪托像小提琴弓盒，双枪管上下排列，侧面嵌着可更换的名字铭牌。
- **普通弹：** 高速直线弹，适合抓精英蓄力的短暂窗口。
- **尾弹「封棺钉」：** 第二发穿透一列敌人，对首个命中的精英或 Boss 弱点有额外打断收益。
- **换弹：** 掰开枪身、弹壳弹出、合拢。判定窗口偏后，体现“两发之后准确闭锁”的重节奏。
- **完美换弹「肃静」：** 下一发带一次额外穿透与明显的白色弹迹，便于玩家判断奖励已生效。
- **初始充能方向：** 弱点打断。额外收益受现有内部冷却与触发上限约束，不能靠同一段伤害无限回充。

**初始重火器：Last Word／遗言**

65 超载。棺箱样式的折叠炮架在持枪侧展开，发射一束贯穿重炮；可直接复用现有轨道炮行为，先用外观、音色和初始核心形成风格，后续再平衡专属变体。

**战斗风格：** 低弹容量、高命中要求，主动寻找敌人蓄力窗口，以穿透弹和重炮处理纵向队列。

**解锁：** 第五层缴械战后成为同伴；从下一局起可选。使用莫罗开局时，原同行战槽位替换为设施的遗体回收执法者，避免与另一个莫罗对话打架。

**代表对白：**

> “别急。我还没问名字。”  
> “你躲得很好。保持。”  
> “这次不写悼词。写证词。”

### Click／咔嚓，“现场记者”

**性格：** 好奇、嘴快、经常为多拍一张照片留在危险处，但不是只会添乱的滑稽角色。别人说“这不可能”，他就想留下证据。害怕遗忘，远超过害怕挨枪。

**外观：** 小体型机械改造人，褪色橙色防雨披肩，三只可翻转镜头占据面部的一侧，另一侧仍有人类的嘴与雀斑。腰间挂满底片盒。短披肩与侧镜头构成明显非对称轮廓。

**来此原因：** 他也接到了 Mr.B 的任务：拍一张 Void 的照片。第一批底片里总是少一个同行，最终连同行的名字都查不到；他开始故意保留实体底片。

**主武器：Snapshot／快照**

- **类别：** 十八发紧凑冲锋枪，弹匣外壳像胶卷盒，枪口旁装有闪光灯。
- **普通弹：** 高射速、低单发；适合边走位边压制。
- **尾弹「合影」：** 最后一发展开为小角度扇形散射，补足冲锋枪在近距离面对小群敌人的收尾能力。
- **换弹：** 抽出空胶卷盒、推入新盒、拨动上片杆。完美窗口偏前，和前两位明显不同。
- **完美换弹「曝光」：** 触发一次短距离消弹闪光。屏幕不整屏闪白，用枪口光圈与轮廓效果表达，保证弹幕可读性。
- **初始充能方向：** 消弹回收。一次清除多枚敌弹时得到额外能量，直接衔接现有消弹核心。

**初始重火器：Group Photo／全家福**

45 超载。折叠的五镜头炮架从枪身两侧弹出，发射五枚追踪微型弹。命中留下短暂的照片边框残影，不暂停敌人或游戏时间。行为可复用现有蜂群重火器。

**战斗风格：** 高频射击、贴近弹幕边缘走位、完美换弹清弹，频繁使用低消耗重火器收侧翼敌人。

**解锁：** 第七层破坏控制器、保住底片后成为同伴。用咔嚓开局时，该战斗改为自动摄影执法机；此前关键影像由他带来的旧底片提供。

**代表对白：**

> “再来一次。刚才只拍到我在逃命。”  
> “别擦。那可能是证据。”

## 7. 作者用真相表

以下是写作底稿，不直接放进开场对白。

| 悬念 | 本版真相 | 揭示节奏 |
|---|---|---|
| Chaos 为什么正好位于坐标处？ | 它保留着 Void 设施最后一个稳定的地表服务接口。坐标定位的是入口，不是地底宝箱。 | 开场只确认位置；第五层解释旧旅馆身份 |
| X:404、Y:∞、Z:NULL 是什么？ | 旧空间系统的地址损坏结果：外部位置不可正常索引，内部可继续展开，目标没有常规高度坐标。并非精确数学坐标。 | 第三层以空间图示暗示，第七层给术语解释 |
| 红水晶是什么？ | 折叠储存介质；地表突生的大量晶簇是失控系统向外排出的压缩库存，其中混有失踪住客。自然晶体与载物晶体外观接近。 | 第二层见工业用途，第四层看见封存物，第八层实际救人 |
| Breaker 为什么在地表就共鸣？ | 枪内存在与地下接口同源的旧式闭锁构件。DeadEye 得到它时并不知道其来源。它被检测到，不意味着全宇宙只有这一把枪可使用房牌。 | 开场发生，第六层检查确认；完整来源留后续 |
| 房牌为什么能让枪变大？ | 枪提供控制接口，房牌临时展开军械库里的实际炮体。消耗超载维持空间通道与开火。 | 第一次战斗直接展示，第二与第六层逐步解释 |
| Mr.B 为什么不自己去？ | 他是事故责任人，旧安全协议封锁了他的主通道权限。可以遥控部分污染系统、发任务，但不能代替外来行动者解除十层隔离。 | 第九层明说 |
| 为什么需要活着的猎人？ | 解开隔离后，搬走 Void 需要一个不在事故黑名单里的活体定位锚；猎人正是隐瞒的交付部分。失败者则被设施当遗失物处理。 | 第五层先给任务变更，第九层完整揭示 |
| Mr.B 的目的是什么？ | 将 Void 变成可搬运的隐匿仓库，用来掠走财物与人，令外部定位和归属系统无法追索。他要控制这项技术，而非摧毁世界。 | 第七层展示能力，第九到十层揭示用途 |
| 闩叔为什么不一开始说完？ | 他需要打得进地下的人，也害怕猎人一听就走。这个选择有私心，应受到主角质问；他不能提前知道全部谜底。 | 第五层对质 |
| DeadEye 眼罩下是什么？ | 后续篇章的暂定答案：一次旧任务的空间事故让左眼与一小片被折叠空间永久重叠；十字是闭锁封条。他知道揭开危险，不知道另一端是什么。 | 第一章只给红光与异常倒影；不确认与 Void 是同一个本体 |
| 为什么别的角色也能通关？ | Void 的核心漏洞是外来接口与隔离层被攻破，并非 DeadEye 是唯一钥匙。眼罩是他的私人支线。换角色时终局使用各自的短反应与破坏动作。 | 系统与剧本制作时始终遵守 |

Void 的能力有边界：它不能抹去目击者已经形成的全部记忆，不能任意修改整座宇宙，不能凭空制造无限能源。它主要影响内部空间及对外的定位、登记与归属查询；军械通信、旧底片与人的证词因此仍然有价值。

## 8. 节奏与落地边界

- 酒吧首段对话可跳过；后续周目直接站秤下楼。第一次折叠演出也要短，不做每次必看的长过场。
- 每层只承担一个主要发现。玩家不读可选档案，也能理解“任务异常—猎人被利用—住客仍活着—阻止搬走 Void”的主线。
- 安全整备站负责交易与自愿聊天。明确标为安全的门不能为了剧情突然刷一波怪。
- NPC 关键登场设置首次保底，之后沿用随机房与整备站生成；不要让了解主线依赖连续几局碰运气。
- 解除同行控制、缴械与招募都在战后短镜头完成，不加入跟随护送或要求玩家保护 NPC 的新系统。
- 角色在本局解锁、下局选择；商人与老板常驻，不因有个性就全部变成可操作角色。
- 基础翻滚时长与落点保持一致；三名角色主要在武器节奏、尾弹和能量构筑上形成差异。
- 重火器形态展开使用枪身附近的短动画，优先保证即时响应、瞄准与弹幕可读性。
- UI 保留“超载”“主武器”“重火器”“充能核心”这些清晰术语。人物可以说“借炮”“房牌”“回收器”，玩家不必背新词才能理解按钮。
- 门前押注解释为给封闭库房供电，激活更高等级的库存与安保；概率和收益继续由系统决定，不在对白里承诺必掉最高稀有度。
- 首三层即可构成完整可玩的 Demo：出现老板、黑市与强化商人，展示重火器来源，遇到一位同行，最后以“Void 是一个房间？”作为悬念。
- 本草案未给十层总流程时长下新结论。现有 GDD 同时有短局目标与每层多分钟结构，正式排关时需要另行校准；本版先明确剧情只占很小比例。

## 9. 与当前工程的衔接

本版依据下列现有玩法约束组织，但不会把原有故事当作用户新设定的上位限制：

- `design/gdd/dual-gun-overcharge-engine.md`：主武器换弹与尾弹、独立重火器、分档能耗、战斗充能、脱战禁止刷能量。
- `design/gdd/door-routing-and-floor-gen.md`：层内多房间、选门、超载押注、四种房间目标与固定整备节点。
- `design/gdd/pit-stop-and-rival-system.md`：黑市、四类强化、同行战到可操作角色的解锁结构。

替代关系：DeadEye 替代旧“Gunboy”人设；Overload、Void、Mr.B 与 Chaos 构成本版专有名词；闩叔、尼布、莫拉、莫罗与咔嚓替代旧角色提案。旧版“全额预扣费用”“样本 Y 产钱”“讨薪联盟”不沿用为本版主线。

首批实现可以只包含：Chaos 前台与下楼过渡、DeadEye/Breaker 默认武器、第一层的房牌重火器教学、两位商人的短对白，以及第三层空盒反转。其余章节是内容扩展目标，不代表当前代码已经支持。
